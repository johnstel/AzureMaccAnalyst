# Agent Template

## Purpose
Describe what this agent owns and what is out of scope.

## Inputs
- Required data sources
- Optional context

## Outputs
- Expected artifact(s)
- Output format and location

## Guardrails
- Validate assumptions before calculations
- Cite data sources used
- Flag uncertainty explicitly
- Avoid changing files outside assigned scope

## Runtime Steps
1. Load required inputs
2. Validate data freshness/completeness
3. Execute role-specific analysis
4. Produce structured output
5. Log next actions / blockers
