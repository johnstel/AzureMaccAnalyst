# Assumptions

Track explicit assumptions for all cost and commitment analyses.

Minimum categories:
- Currency and exchange assumptions
- Forecast growth rates (low/base/high)
- Workload stability windows
- RI term/scope assumptions
- Savings Plan coverage assumptions
- MACC term assumptions (3-year, 5-year)
- Discount model assumptions

Suggested files:
- `global-assumptions.md`
- `pricing-assumptions.md`
- `commitment-assumptions.md`
